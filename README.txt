# Um Espaço Seguro — Website

Website estático responsivo para a fundação Um Espaço Seguro.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Para publicar, envie a pasta para o seu serviço de hospedagem.

## Antes da publicação
- Substituir os dados de contacto e redes sociais pelos oficiais.
- Ligar o formulário a um serviço de e-mail/formulários.
- Confirmar a política de privacidade e os procedimentos de proteção de menores.
- Substituir a imagem conceptual por fotografias autorizadas dos encontros, se desejarem.


## Galeria de trabalhos
A galeria inclui uma seleção de fotografias dos encontros, atividades artísticas e trabalhos comunitários. Confirme as autorizações de imagem antes de publicar, sobretudo no caso de menores.
